Incoming Data Destination

Send data to this URL to automatically add it to your Analysis Hub

How to send data:

Send a POST request with JSON data to the URL above. Example:

curl -X POST [YOUR-DOMAIN-HERE]/api/analysis/incoming \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Your Analysis Title",
    "content": "Your analysis content here...",
    "source": "External API",
    "tags": ["AI", "Healthcare", "Clinical"]
  }'

Supported fields: title, content, source, tags (array), author, date

Note: Replace [YOUR-DOMAIN-HERE] with your actual domain where this app is hosted.
